# ATM Management System (C++)

A console-based ATM Management System developed in C++ using Object-Oriented Programming and File Handling.

## Features
- Create Account
- Login System
- Check Balance
- Deposit Money
- Withdraw Money
- Change PIN
- Data Storage using File Handling

## Technologies Used
- C++
- OOP
- File Handling

## How to Run

```bash
g++ main.cpp -o atm
./atm
```
