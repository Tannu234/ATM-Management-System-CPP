# ATM Management System (C++)

## Features

- Balance Inquiry
- Cash Withdrawal
- Deposit Money
- PIN Verification

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- File Handling
- STL Vector

## Project Structure

ATM Management System/
├── main.cpp
└── accounts.txt

## How to Run

```bash
g++ main.cpp -o atm
./atm
```
