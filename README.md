# ATM Management System (C++)

## Features

- Create New Account
- Secure Login using Account Number and PIN
- Check Account Balance
- Deposit Money
- Withdraw Money
- Change PIN
- Store Account Data in File
- Multiple Account Support

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- File Handling
- STL Vector

## Project Structure

ATM Management System/
├── main.cpp
└── accounts.txt

## How to Run

```bash
g++ main.cpp -o atm
./atm
```
